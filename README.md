# Picking de carga

Página para pickear la carga de camiones desde el celular. No incluye datos de clientes.

## Uso
1. Abre la página en el celular.
2. Carga la planilla del día (.xlsx). Cada hoja (salvo "Resumen") es una ruta.
3. Pickea tocando cada línea. Los adicionales (redespachos) se agregan a mano.
4. En **Reporte** puedes descargar el PDF o copiar el CSV.

Los datos se guardan solo en el navegador de ese celular.
